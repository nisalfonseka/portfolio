# Backlink strategy for nisalfonseka.com

The goal is to earn relevant references to real work, not buy links or create low-quality directory profiles. Every link should help a reader verify a project, research result or professional relationship.

## Priority opportunities

1. SLIIT and COEAI
   - Ask for the COEAI Chatbot and Academic Chatbot Platform to be documented on the relevant SLIIT or faculty project pages.
   - Request a named developer credit linking to the matching case study, where institutional policy permits it.
   - Offer a concise technical summary, adoption figure and approved screenshot so the page is useful rather than promotional.

2. SinAI research
   - Link the canonical SinAI case study from the research repository README, project site, poster, thesis resources and any SLIIT research showcase page.
   - Add the portfolio URL to legitimate Hugging Face model or dataset cards if those artifacts are published.
   - When a paper or abstract becomes public, cross-link the publication, dataset and case study so each source verifies the others.

3. SamadhiRice.lk
   - With the client's approval, add a modest implementation credit on an appropriate About, technology or case-study page.
   - Publish a joint case study only with approved business facts and a reciprocal link to the live product.

4. Technical publishing
   - Expand the existing engineering notes with original diagrams, evaluation methods and reproducible examples.
   - Share them through LinkedIn, relevant Sri Lankan developer communities and technical newsletters using descriptive links to the canonical article.
   - If an article is republished, set its canonical URL to the original nisalfonseka.com page when the platform supports it.

5. Developer profiles and repositories
   - Link each public repository to its exact portfolio case study, and link the case study back to the repository when public.
   - Keep the GitHub profile README, LinkedIn Featured section and verified organization profiles consistent with the canonical domain.

6. Events and recognition
   - For real hackathons, presentations or meetups, request links from official event recap, speaker or winner pages.
   - Never create or imply an event achievement that cannot be supported by an organizer page, certificate or photo.

## Outreach sequence

1. Prepare one approved URL, a 40-60 word description, one image and the exact factual claim for each target.
2. Contact the person responsible for the existing page rather than sending bulk outreach.
3. Explain what reference would improve their page and where the portfolio provides supporting detail.
4. Follow up once after 7-10 days, then stop unless they respond.
5. Record the source page, target page, contact, date, outcome and whether the link is live.

## Measurement

- Track new relevant referring domains and referral visits in Search Console and analytics.
- Monitor branded searches and impressions for project-specific terms.
- Review which case studies attract links and expand those with stronger first-party evidence.
- Audit links quarterly for broken or redirected targets.
- Do not use domain-authority scores as the primary success measure; relevance, legitimacy and qualified visits matter more.
